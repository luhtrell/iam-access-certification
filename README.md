# IAM Access Certification and Audit Automation

A PowerShell-based Identity and Access Management (IAM) portfolio project that identifies unauthorized access, detects access retained by terminated employees, validates access review decisions, and generates audit reports using fictional identity data.

## Overview
A PowerShell-based identity and access governance lab that evaluates
sample employee access against an approved-role matrix, identifies
potential access violations, validates review decisions, and generates
CSV audit reports.

All identities and access records in this project are fictional.

## Objectives
- Compare assigned roles with approved roles by department and job title.
- Detect access retained by terminated employees.
- Record and validate access review decisions.
- Generate findings, summary, validation, and audit trail reports.

## Project Structure
- `data/` — fictional employee, approved-role, and access assignment data
- `scripts/` — PowerShell audit and reporting scripts
- `reviews/` — sample access review decisions
- `reports/` — generated CSV reports
- `tests/` — test scenarios
- `docs/` — project documentation

## Scripts
- `Find-AccessViolations.ps1` — identifies unauthorized roles and terminated employee access.
- `Export-AuditReport.ps1` — summarizes findings by severity and type.
- `Test-ReviewDecisions.ps1` — validates that findings have documented review decisions.
- `New-AuditTrail.ps1` — combines findings and review decisions into an audit trail.
- `Update-RemediationTracker.ps1` — creates or updates the remediation tracker while preserving existing remediation progress.
- `Update-RemediationStatus.ps1` — updates a finding's remediation status, owner, and notes, with validation for closure notes.

## How to Run

Open PowerShell in the project root and run the scripts in the following order:

```powershell
.\scripts\Find-AccessViolations.ps1
.\scripts\Run-AllTests.ps1
.\scripts\Test-ReviewDecisions.ps1 -ReviewFile "sample-review-decisions.csv"
.\scripts\New-AuditTrail.ps1
.\scripts\Update-RemediationTracker.ps1
.\scripts\Export-AuditReport.ps1
```

The test runner checks five review-validation scenarios: valid decisions, duplicate decisions, incomplete reviews, invalid decisions, and missing decisions.

Use `Update-RemediationStatus.ps1` to record remediation progress. Review the generated reports in `reports/` after running the workflow.
```

Run the scripts in this order because later scripts use reports
generated by earlier scripts.

## Sample Results
The sample dataset is designed to produce two findings:
1. An unauthorized Finance_Approver role assigned to a Financial Analyst.
2. CRM_Read access retained by a terminated employee.

## Testing

The project includes automated checks for the expected baseline findings and access review decision validation.

- Baseline tests verify detection of unauthorized roles and terminated-employee access.
- Review validation tests cover recorded, missing, duplicate, incomplete, and invalid decisions.
- Latest observed review-validation result: **5 passed, 0 failed**.

These results reflect the test runs completed during project development.

## Limitations
This is a simulated portfolio lab. It does not connect to a production
identity provider, remove real access, or provide tamper-proof logging.
Findings and decisions must be validated before real-world remediation.
